# STDD artifacts — curated snapshot

Sanitized snapshot of the spec-test-driven development (STDD) artifacts behind the Rust rewrite (renderer-parity) and the TUI change: specs, designs, task lists, and execution ledger.

Working files stay out of this repo by design (see `.gitignore`); this folder is the published audit trail. Local paths and machine identifiers were removed before publishing. Frontmatter fingerprint values are preserved verbatim as the historical record; gate originals live in the working tree.
